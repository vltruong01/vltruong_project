# Projects

Truong builds personal and academic projects related to Data Science, Artificial Intelligence, web applications, and chatbot systems.

This chatbot project is a local RAG-style personal knowledge chatbot. It uses SentenceTransformer embeddings and cosine similarity to retrieve relevant markdown knowledge chunks, then composes an answer only from retrieved content.

The chatbot does not use OpenAI API, Gemini API, Claude API, paid AI APIs, GPU, Redis, PostgreSQL, or any cloud vector database.

Vietnamese summary: Dự án chatbot này dùng FastAPI, SentenceTransformer, cosine similarity và knowledge base markdown để trả lời dựa trên dữ liệu có sẵn.
